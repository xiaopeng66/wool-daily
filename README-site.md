# wool-daily 羊毛日报

每天 9/15/21 点自动更新的羊毛推荐表：23 个福利源聚合、规则打分排序、
只展示上一轮之后的新线索（看过没发的自动沉底）。

- 最新一期：`index.html`
- 归档：`2026-MM-DD.html`

数据源与打分规则：23 个源（生活羊毛/软件限免/云资源/AI 额度/TG 线报/科技新闻），
规则打分后只留上一轮之后的新线索。

本仓库同时包含生成脚本（`wool_daily.py` / `run-daily.sh`，2026-10-26 起）：
抓取层复用 baipiao-daily skill 的 `fetch_sources.py`，所以本仓库需配合该 skill 才能独立跑。
